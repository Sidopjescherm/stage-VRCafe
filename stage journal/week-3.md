# Week 3 van stage

In de derde week van stage zijn er een aantal interessante situaties gebeurd. In deze derde week hbe ik ook maandag de code conventies verder gemaakt en heb ik twee blogs geschreven voor het VRcafe. Een van de blogs heeft een onderwerp over de terracotta krijgers en de ander gaat over de VR in zorginstellingen.

Op dinsdag was ik bezig met de nieuwe code conventies afmaken, maar toen ik eenmaal bezig was met werk kwam er een spontane booking binnen. Nu moest ik samen met een andere backend/frontend developer dit oplossen. Ik heb na deze gebeurtenis gesproken met mijn stagebegeleider, omdat ik een frontend stage heb en geen gastpersoon stage volg. Na dit gesprek zijn er wat afspraken gemaakt over het vervolg van dit.

Op woensdag heb ik mijn code conventies, blogs en user stories getoond aan Dirk Kuiper. Dirk vond de code conventies prima voor ons als we er wat aan hebben en vond de blogs wel leuk, maar te niche voor SEO. Ook waren de user stories voor hem wat beter kon veranderen qua to do's, maar mijn stagebegeleider noemt het ook user stories, dus dat blijft onveranderd.

Donderdag ben ik begonnen met mijn eigen website maken voor de stage die ik ga lopen en waar deze journals gelezen kunnen worden. Omdat het niet een super grote website zal worden heb ik een minimalist ontwerp. Later op de dag was er geen begeleiding of stagebegeleiding aanwezig dus moesten we samen met de stagiaires twee boekingen tegelijkertijd draaien.

Op vrijdag ben ik verder gegaan met de website en heb ik een groot deel van de website ontworpen. Verder heb ik breakdown schetsen gemaakt van mijn gemaakte ontwerpen zodat ik beter begrijp hoe ik het zal moeten bouwen.
